# Workflow

Use Vue Composition API and TypeScript. Keep semantic UnoCSS tokens in app/assets/unocss and CSS variable values in app/assets/css/tokens.css. Read PRODUCT.md and DESIGN.md before changing scope or visual direction.

Run pnpm test, pnpm typecheck and pnpm build. Check production output for inspector artifacts. Browser work must preserve unrelated sessions, close owned tabs and track any owned processes.
